# 强化学习算法分类维度

## 是否学习环境
- **Model-free**：不建模 $P(s'|s,a)$ 和 $r$。Q-learning、DQN、PPO、SAC 等绝大多数经典算法。
- **Model-based**：先学（或已知）环境模型，再用它模拟环境训练。AlphaGo、World Model。

## 优化目标
- **Value-based**：只学 $Q(s,a)$，决策时取 argmax Q，无显式策略网络。DQN 系。样本效率高，但只适合离散动作（连续空间取 max 本身就是优化问题）。
- **Policy-based**：直接参数化 $\pi(a|s)$，梯度上升优化期望回报。REINFORCE、TRPO、PPO。天然支持连续动作和随机策略，但方差大、样本效率低。
- **Actor-Critic**：Actor 决策，Critic 打分降方差，即"用 value-based 稳定 policy-based"。A2C/A3C、DDPG、TD3、SAC。当前主流框架。

## 数据利用方式
- **Off-policy**：可用任意历史策略产生的数据，因此能维护经验回放池反复复用。DQN、DDPG、SAC。样本效率高，收敛稳定性较难保证。
- **On-policy**：只能用当前策略产生的数据，策略一更新旧数据即作废。REINFORCE、PPO、TRPO。更新稳定但数据用一次就扔。

## 动作空间
- **Discrete**：有限动作集，可遍历取最大。DQN 系。
- **Continuous**：动作取值连续、无穷多，无法遍历。做法是让策略网络直接输出动作（如高斯分布的均值方差后采样）——这也是连续控制领域几乎被 policy-based / actor-critic 占据的原因。DDPG、TD3、SAC、PPO。

## 更新时机
- **蒙特卡洛 (MC)**：跑完整个 episode 拿到真实回报 $G_t$ 再更新。
$$V(s_t) \leftarrow V(s_t) + \alpha[G_t - V(s_t)]$$
无偏，但必须等回合结束、方差大。代表：MC 控制、REINFORCE。

- **时序差分 (TD)**：每走一步就更新，用"即时奖励 + 下一状态价值估计"做目标，即贝尔曼自举。
$$V(s_t) \leftarrow V(s_t) + \alpha[r_{t+1} + \gamma V(s_{t+1}) - V(s_t)]$$
其中 $\delta_t = r_{t+1} + \gamma V(s_{t+1}) - V(s_t)$ 称为 **TD 误差**。
可在线逐步更新、方差小，但有偏（目标里的 $V(s_{t+1})$ 本身也是未收敛的估计）。代表：TD(0)、Q-learning、SARSA、DQN。

- **折中**：n-step TD / TD(λ)，往前看 n 步真实奖励再用估计值收尾，在偏差和方差间可调。

## 是否在线交互
- **Online RL**：不断与环境交互，边采集边使用，策略持续进化。适合试错成本可接受的场景（游戏、仿真）。
- **Offline RL**：完全不交互，只用一批固定数据集学策略，部署前没机会验证。
  - 核心问题：**OOD 动作** —— 数据集未覆盖的状态-动作对价值估计可能严重失真（如高估从未尝试过的动作），且无法通过实际试错纠正。故通常加约束让策略别偏离数据分布太远。
  - 适用：试错代价极高的自动驾驶、医疗、金融。代表：CQL、BCQ、IQL、Decision Transformer。

概念辨析：
1. Offline 一定是 off-policy —— 对，训练数据必然不来自当前策略。
2. Off-policy 一定是 offline —— 错，数据可来自不同策略，但智能体仍可持续交互补充经验池。

文档未列的补充维度：两者都属**最大熵（soft）系**，有 `log_alpha` 自动调温，`target_entropy = -act_dim * scale`（[diffv2.py:128](file:///data/home/zch_zhou28/workspace/work2026/DPRL_V2/diffusion_policy_online_rl/relax/network/diffv2.py#L128)）。但熵是用探索噪声尺度 `exp(log_alpha)*noise_scale` 近似的（[sdac.py:174](file:///data/home/zch_zhou28/workspace/work2026/DPRL_V2/diffusion_policy_online_rl/relax/algorithm/sdac.py#L174)），并非真正计算 $\log\pi$。

## 两者的实际差异（均在 policy loss 内）

**DPMD**：加权行为克隆式。先采动作 `next_action`，正向加噪 `q_sample`，再用 $w=\exp(\text{clip}(\hat Q)/\alpha)$ 加权做去噪回归（[dpmd.py:129-142](file:///data/home/zch_zhou28/workspace/work2026/DPRL_V2/diffusion_policy_online_rl/relax/algorithm/dpmd.py#L129-L142)）。权重是**无归一化的指数**，依靠 running mean/std 归一化 Q 后 clip 到 ±3 防止数值爆炸。属镜像下降 / 加权回归路线。

**SDAC**：反向采样 + 自归一化重要性加权。在每个扩散步 $t$ 从 $\tilde a_t$ 出发采 64 个 MC 噪声，经 `get_recon` 重建 $\hat a_0$，对候选算 Q 后做 **logsumexp softmax** 得权重（[sdac.py:154-166](file:///data/home/zch_zhou28/workspace/work2026/DPRL_V2/diffusion_policy_online_rl/relax/algorithm/sdac.py#L154-L166)），再回归噪声。相当于用自归一化逼近 $\pi^*\propto\exp(Q/\alpha)$ 的反向条件分布，权重天然落在 [0,1] 且每行和为 1，比 DPMD 的裸指数权重更稳定。

结论：**Model-free、Actor-Critic、Off-policy、Continuous、TD(0)、Online、最大熵** —— 两者一致；SDAC 可视为 DPMD 在权重估计上的改进版。
